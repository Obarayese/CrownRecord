# CrownRecord

**CrownRecord** is a free Windows screen recorder from **[Crown Softech](https://crownsoftech.com)** — part of the Crown product line (CrownWatch, CrownWP, CrownSoft).

- 1080p VP9 + Opus (12 Mbps / 256 kbps)
- Webcam bubble, invisible teleprompter, mic + system audio
- Zoom, Google Meet, Teams (window capture — no paid cloud recording)

**Support:** [support@crownsoftech.com](mailto:support@crownsoftech.com)

## Download

Windows installers: see **[DOWNLOAD.md](./DOWNLOAD.md)** and [GitHub Releases](https://github.com/CrownSoftech/CrownRecord/releases).

## Logs (for you and users)

Users click **Open log folder** in the app. Logs live under `%APPDATA%\crownrecord\logs\`.

See **[docs/LOGS-AND-SUPPORT.md](./docs/LOGS-AND-SUPPORT.md)**.
