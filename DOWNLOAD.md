# Download CrownRecord

Free Windows screen recorder by **[Crown Softech](https://crownsoftech.com)**.

**Support:** [support@crownsoftech.com](mailto:support@crownsoftech.com)  
**Product page:** [crownsoftech.com/crownrecord](https://crownsoftech.com/crownrecord)

## Install

1. Open **[GitHub Releases](https://github.com/Obarayese/CrownRecord/releases/latest)**.
2. Download:
   - **CrownRecord-*-Setup.exe** — installer (recommended)
   - **CrownRecord-*-Portable.exe** — run without installing
3. Allow **screen**, **microphone**, and **camera** when Windows asks.

## What’s new in v0.4.0

- **720p default** for smoother recording on slower PCs
- **Floating Pause/Stop bar** while the main window minimizes
- **Enhanced mic noise suppression** and **voice boost** slider
- **Grouped sources** — screens, meetings, and app windows
- **Auto-refresh** when you plug in a mic or camera
- **Post-save dialog** — open file, open folder, or done
- Shows as **CrownRecord** in Task Manager (with `build/icon.ico`)

## Record Zoom, Google Meet, or Teams

1. Join your meeting as usual.
2. In CrownRecord, pick a source under **Meetings & browsers** (★ items).
3. Turn on **Microphone** (your voice) and **Computer audio** (other participants).
4. Optional: **Webcam bubble** and **Teleprompter**.
5. **Start recording** → use the floating bar to **Pause** or **Stop** → save locally.

You do **not** need the meeting host to enable Zoom/Meet **cloud** recording.

## Performance tips

- Leave quality on **720p** unless you need full 1080p.
- Turn **Webcam bubble** off if CPU usage is high — screen-only capture is much lighter.
- Close other heavy apps while recording long meetings.

## File format

- **WebM** — default, best quality in the app (plays in Chrome, Edge, VLC).
- **MP4** — select in the app if your PC supports it.
