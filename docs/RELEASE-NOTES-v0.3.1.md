# CrownRecord v0.3.1

Free Windows screen recorder by **Crown Softech**.

## Download

- **CrownRecord-0.3.1-Setup.exe** — recommended installer  
- **CrownRecord-0.3.1-Portable.exe** — no install, run directly  

## What’s new

- **Live preview** while recording (screen + webcam bubble)
- **Choose microphone and camera** (built-in or external) before you record
- **Save format:** WebM (recommended) or MP4 when your PC supports it
- Record **Zoom, Google Meet, Teams** locally — no host cloud recording required
- **Loom-style** webcam bubble + invisible teleprompter
- Mic + computer audio mixed into one file
- Logs folder in app for support

## Requirements

- Windows 10/11 (64-bit)
- Allow screen, microphone, and camera permissions when prompted
