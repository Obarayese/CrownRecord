## Log files (troubleshooting)

If something goes wrong, send us a log file:

1. Open CrownRecord → **Open log folder**
2. Attach the newest `crownrecord-YYYY-MM-DD.log`
3. Email **support@crownsoftech.com** with what you were doing (e.g. Zoom, Google Meet, which window you selected)

While recording, use the **floating bar** (Pause / Stop) if the main window is minimized. If the PC feels slow, use **720p** quality and turn off the **webcam bubble**.

### Where logs are stored (Windows)

`%APPDATA%\crownrecord\logs\`

### Privacy

Logs contain technical events (errors, capture start/stop). They do **not** include your video or teleprompter script text.
